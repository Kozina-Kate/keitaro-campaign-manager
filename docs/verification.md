# Итоговая проверка

Дата: 19 ноября 2026 года.

## Чистая установка

Создана отдельная копия только отслеживаемых файлов репозитория и новое
виртуальное окружение Python 3.14.7 на macOS ARM64. `.env`, рабочая база данных
и API-ключ не переносились.

Установка выполнена командами из README:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
python -m pip install -e . --no-deps
python -m pip check
```

Результат: установка успешна, конфликтов зависимостей нет.

## Автоматические проверки

- `pytest -q`: 45 тестов успешно.
- `ruff check .`: замечаний нет.
- `node --check app/static/app.js`: успешно.
- `node --check app/static/editor.js`: успешно.
- `alembic upgrade head`: схема создана до версии `0003`.
- `alembic check`: расхождений моделей и схемы нет.
- `alembic downgrade base` и повторный `alembic upgrade head`: успешно
  на отдельной пустой тестовой базе.

Тесты покрывают создание двух потоков, повторные запросы, частичные ошибки,
черновики и их отмену, архив и восстановление, внешнее удаление, закрепление
долей, округление, конфликт версий и таймауты публикации до/после применения PUT.

Исправлена проверка `/health`: до применения всех миграций она возвращает `503`,
включая промежуточные версии `0001` и `0002`. Проверяются таблицы и столбцы всех
моделей, записи пользователей не читаются.

В локальном запуске тестов есть предупреждение Starlette об устаревшем адаптере
HTTPX в TestClient. Это предупреждение зависимости; ошибок и пропущенных тестов
нет. Версии зависимостей зафиксированы.

## Границы проверки

В выданном аккаунте доступен один оффер, поэтому реальные сценарии нескольких
офферов не выполнялись. Они покрыты автоматическими тестами. Дополнительная
live-проверка внешнего удаления с временным выключением кампании была
заблокирована автоматической проверкой разрешений и не проводилась.

Реальные рекламные переходы и определение страны по пользовательскому IP
не проверялись. Параллельное внешнее изменение списка между GET и PUT нельзя
сделать атомарным средствами используемого клиента; ограничение описано в README.

Приложение предназначено для локального тестового использования. Для публичного
размещения потребуется аутентификация пользователей.
